# 할 일 관리 앱(Todo App) PRD

## 1. 프로젝트 개요

### 1.1 프로젝트명

**하루체크(Haru Check)**

### 1.2 프로젝트 유형

모바일 전용 할 일 관리 앱

### 1.3 프로젝트 목적

사용자가 해야 할 일을 간단하게 등록하고 날짜별로 관리하며, 완료 여부와 하루의 진행 상황을 쉽게 확인할 수 있는 모바일 Todo 앱을 제작한다.

복잡한 기능보다는 다음 핵심 흐름에 집중한다.

**할 일 등록 → 오늘 할 일 확인 → 완료 체크 → 진행률 확인**

### 1.4 핵심 가치

> "오늘 해야 할 일을 쉽고 간단하게 관리한다."

사용자가 앱을 실행한 후 최소한의 조작으로 오늘 해야 할 일을 확인하고 새로운 할 일을 추가할 수 있도록 한다.

# 2. 주요 사용자

### 주요 타깃

- 학생
- 직장인
- 프리랜서
- 개인 일정 관리가 필요한 사용자
- 복잡한 일정 관리 앱이 부담스러운 사용자

### 사용자 요구사항

사용자는 다음과 같은 경험을 원한다.

- 해야 할 일을 빠르게 등록하고 싶다.
- 오늘 해야 할 일만 확인하고 싶다.
- 중요한 일을 구분하고 싶다.
- 완료한 일을 쉽게 체크하고 싶다.
- 날짜별 일정을 확인하고 싶다.
- 오늘 얼마나 일을 완료했는지 확인하고 싶다.

# 5. 스플래시 화면

## 목적

앱 실행 시 브랜드를 보여주고 홈 화면으로 이동한다.

### 구성

- 앱 로고
- 앱 이름
- 간단한 슬로건

### 예시

```text
        ✓

     하루체크

오늘 해야 할 일을
하나씩 완료해 보세요.
```

일정 시간이 지나면 자동으로 홈 화면으로 이동한다.

# 6. 홈 화면

## 목적

사용자가 오늘 해야 하는 일을 가장 빠르게 확인하는 핵심 화면이다.

### 상단 영역

```text
안녕하세요 👋

오늘도 하나씩 해볼까요?

8월 25일 화요일
```

### 진행률 영역

```text
오늘의 목표

████████████░░░░░░

3 / 5 완료

60%
```

### 오늘의 할 일

```text
오늘의 할 일

○ 병원 예약하기
  오전 10:00

○ 웹디자인 과제하기
  오후 2:00

✓ 장보기
  완료

○ 운동하기
  오후 7:00
```

### 할 일 추가 버튼

화면 오른쪽 아래에 Floating Action Button을 배치한다.

```text
        ＋
```

버튼을 누르면 **할 일 추가 화면**으로 이동한다.

# 9. 캘린더 화면

## 목적

날짜별로 등록된 할 일을 확인한다.

### 화면 예시

```text
       2026년 8월

 <                   >

일 월 화 수 목 금 토

23 24 25 26 27 28 29
       ●
```

할 일이 존재하는 날짜에는 작은 표시를 보여준다.

날짜를 선택하면 아래에 해당 날짜의 할 일을 표시한다.

```text
8월 25일

○ 병원 예약하기

○ 웹디자인 과제하기

○ 운동하기
```

# 13. 할 일 완료 기능

할 일 왼쪽에 체크박스를 배치한다.

### 미완료

```text
○ 운동하기
```

### 완료

```text
✓ 운동하기
```

완료하면 텍스트에 취소선을 적용할 수 있다.

```text
✓ ~~운동하기~~
```

완료 처리와 동시에 오늘의 진행률을 다시 계산한다.

---

# 14. 오늘의 진행률

오늘 등록된 전체 할 일과 완료된 할 일을 계산한다.

### 계산 방식

```text
완료 개수 ÷ 전체 할 일 × 100
```

예를 들어

```text
전체 할 일 = 5개

완료 = 3개

3 ÷ 5 × 100 = 60%
```

따라서 화면에는 다음과 같이 표시한다.

```text
오늘의 목표

60%

3 / 5 완료
```

Progress Bar도 함께 표시한다.

# 15. 중요도

중요도는 3단계로 구성한다.

| 중요도 | 의미             |
| --- | -------------- |
| 중요  | 반드시 처리해야 하는 일  |
| 보통  | 일반적인 할 일       |
| 낮음  | 여유가 있을 때 처리할 일 |

색상만으로 중요도를 표현하지 않고 텍스트 또는 아이콘을 함께 사용한다.

+

+

+

```text
+ 버튼
↓
할 일 입력

```

### ② 등록한 할 일을 확인할 수 있다.

```text

```

```text

```

LocalStorage에 데이터를 저장한다.

# 26. 최종 목표

하루체크의 첫 번째 목표는 기능이 많은 앱을 만드는 것이 아니다.

사용자가 앱을 열었을 때

**“오늘 내가 무엇을 해야 하는지 바로 알 수 있는 앱”**

을 만드는 것이 핵심이다.

따라서 1차 개발에서는 다음 경험을 가장 중요하게 설계한다.

**빠른 등록 → 쉬운 확인 → 간단한 완료 → 성취감 있는 진행률 확인**

이 네 가지 경험을 완성한 후 캘린더, 알림, 반복 일정, 통계, 로그인 및 클라우드 동기화 기능을 단계적으로 추가한다.
