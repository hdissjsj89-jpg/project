**대상 디바이스** Desktop 우선 (Responsive 확장 고려)

## 1. 프로젝트 개요

### 1.1 배경
AI 도입은 늘고 있지만, 정작 실무 현장의 직장인들은 "어디서부터, 어떻게 써야 할지" 막막해하는 경우가 많다. 본 서비스는 이론이 아닌 **실무 적용 가능한 AI 협업 방법**을 제공하여, 직장인의 업무 생산성을 높이고 반복 업무에서 벗어나 **창의적인 일에 집중하는 즐거움**을 되찾아주는 것을 목표로 한다.

### 1.2 서비스 한 줄 정의
> AI 활용이 막막한 직장인을 위한, 오늘부터 바로 쓰는 실무형 AI 협업 솔루션

### 1.3 목적
- 랜딩페이지를 통해 서비스의 핵심 가치를 명확히 전달
- 방문자를 상담 신청 / 콘텐츠(자료) 다운로드 리드로 전환
- 잠재 고객의 이름·이메일·전화번호를 수집하는 팝업 폼 구현

### 1.4 타겟 사용자
| 구분 | 내용 |
|---|---|
| 주요 타겟 | AI를 업무에 써보고 싶지만 방법을 몰라 막막한 직장인 (실무자~팀장급) |
| 니즈 | "이론 강의 말고, 오늘 내 업무에 바로 쓸 수 있는 방법"을 원함 |
| 페인포인트 | 반복적인 단순 업무에 시간 소모, AI 도구는 많지만 실무 적용법을 모름 |
| 원하는 결과 | 업무 생산성 향상 + 반복 업무 축소 + 창의적 업무에 집중할 여유 확보 |

## 2. 핵심 콘텐츠 구조 (3대 주제 & 핵심 메시지)

랜딩페이지는 아래 3개 섹션을 순서대로 배치하여 **"인식 전환 → 실행 방법 → 정체성/브랜드"** 순의 스토리라인을 구성한다.

### 주제 1. AI로 일하는 방식이 어떻게 달라지는지
- **핵심 메시지:** 막막함은 줄이고, 일은 더 빠르고 똑똑하게
- **콘텐츠 방향:** Before/After 형태로 기존 업무 방식과 AI 협업 후 업무 방식을 대비. 정서적 공감(막막함)에서 기대감(빠르고 똑똑하게)으로 전환
- **역할:** Hero 섹션 직후 첫 공감 포인트, 방문자의 문제의식을 자극

### 주제 2. 직장인을 위한 실무형 AI 협업법
- **핵심 메시지:** 이론이 아니라, 오늘 바로 써먹는 AI 활용
- **콘텐츠 방향:** 실제 업무 시나리오(보고서 작성, 회의록 정리, 데이터 분석, 기획안 초안 등) 기반의 구체적 활용 사례 제시. "당장 실행 가능함"을 시각적으로 증명 (Before/After 예시, 실제 결과물 캡처 등)
- **역할:** 신뢰 구축 및 서비스 차별점(실무 밀착형) 전달

### 주제 3. AI와 함께 더 창의적으로 일하는 사람의 브랜드
- **핵심 메시지:** 생산성을 넘어, 더 가치있는 일에 집중하는 사람
- **콘텐츠 방향:** 단순 효율 도구가 아닌 "일하는 사람의 정체성/브랜드 가치 상승"으로 메시지 확장. 반복 업무에서 해방된 시간을 창의적 업무·자기 성장에 쓰는 사람의 모습을 제시 (감성적 클로징)
- **역할:** CTA 직전 배치, 감정적 동기부여로 전환율 극대화

## 3. 페이지 구성 (섹션별 와이어프레임 레벨 정의)

| # | 섹션 | 핵심 내용 | CTA 여부 |
|---|---|---|---|
| 1 | Hero | 서비스 한 줄 정의 + 서브카피 + 메인 CTA 버튼 | O (상담/콘텐츠 신청) |
| 2 | 주제1 - 변화 제시 | "막막함 → 빠르고 똑똑하게" Before/After | - |
| 3 | 주제2 - 실무 사례 | 직무별 AI 협업 예시 3~4개 카드 | O (보조 CTA) |
| 4 | 신뢰 요소 | 후기/성과 지표/누적 이용자 수 등 (선택) | - |
| 5 | 주제3 - 브랜드 메시지 | 감성적 클로징 메시지 + 비주얼 | - |
| 6 | 최종 CTA 섹션 | 강한 행동 유도 문구 + 버튼 | O (팝업 오픈) |
| 7 | Footer | 회사 정보, 약관, 문의처 | - |

## 4. CTA 및 리드 수집 팝업 (핵심 기능 요구사항)

### 4.1 트리거
- Hero 섹션 CTA 버튼 클릭
- 주제2 섹션 보조 CTA 버튼 클릭
- 최종 CTA 섹션 버튼 클릭
- (선택) 페이지 이탈 의도 감지 시 Exit-intent 팝업

### 4.2 팝업 유형 (2트랙 제안)
사용자가 원하는 행동을 선택할 수 있도록 팝업 상단에 탭/토글 제공:
1. **무료 상담 신청** — 담당자와 1:1 상담 연결
2. **무료 콘텐츠(가이드) 받기** — 실무형 AI 활용 가이드 PDF 등 즉시 제공

> 두 트랙 모두 동일한 정보 입력 폼을 사용하되, 버튼 문구와 팝업 헤드카피만 분기 처리

### 4.3 입력 필드 (필수)
| 필드명 | 타입 | 유효성 검증 |
|---|---|---|
| 이름 | text | 필수, 2자 이상 |
| 이메일 주소 | email | 필수, 이메일 형식 검증 |
| 전화번호 | tel | 필수, 숫자/하이픈 형식 검증 (예: 010-0000-0000) |

### 4.4 부가 요소
- 개인정보 수집·이용 동의 체크박스 (필수, 약관 링크 포함)
- 마케팅 정보 수신 동의 체크박스 (선택)
- 제출 버튼: "상담 신청하기" / "가이드 받기" (트랙에 따라 문구 분기)
- 제출 완료 시 확인 메시지(Toast/Modal) 노출 → "담당자가 영업일 기준 1일 내 연락드립니다" 등

### 4.5 UX 요구사항
- 팝업은 모달(오버레이) 형태, 배경 클릭 또는 X 버튼으로 닫기 가능
- 입력 오류 시 필드 하단에 인라인 에러 메시지 표시
- 제출 중 로딩 상태 표시, 중복 제출 방지
- 데스크탑 기준 팝업 폭 480~560px, 중앙 정렬
